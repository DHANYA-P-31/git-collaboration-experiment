# Git and GitHub Collaboration Workflow

## Experiment 12

This repository demonstrates Git version control and GitHub collaboration.

### Objectives
- Initialize a local Git repository.
- Connect the repository to GitHub.
- Create and manage branches.
- Commit changes with meaningful messages.
- Push branches to GitHub.
- Create, review, and merge a pull request.
- Explore Git integration using a desktop client.
## Git Workflow Demonstration

1. Create a local repository.
2. Connect it to a remote GitHub repository.
3. Create a feature branch.
4. Commit changes with meaningful messages.
5. Push the feature branch to GitHub.
6. Submit a pull request for review.
7. Merge the approved pull request.
